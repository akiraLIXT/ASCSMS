# ASCSMS - Capstone Project
MINI CAPSTONE for my 2nd year with the boys titled “An Automated Stock Management System for the School Canteen of Philippine Christian University – Manila” 


# Project Overview
The objective of this project is to develop an Automated School Canteen Stock Management System (ASCMS) that can help enhance the efficiency and support any institutions canteen with managing their services.
